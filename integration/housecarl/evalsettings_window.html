Worldspace evaluation settings

Each choice is set to a default with its reason. Change what you want and press Save. Every later evaluation reads these choices without showing this page; reopen it with evalsettings.py window. Saved to {{FILE}}.

A named model runs through the houseCARL plugin's agent for that model, in Claude Code only; another host refuses the step rather than use a different model. "session" uses the model of the session you run the evaluation in.
